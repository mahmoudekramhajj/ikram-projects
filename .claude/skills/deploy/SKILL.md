# نشر Apps Script (clasp)

## الخطوات الإلزامية — بالترتيب، لا تتخطَّ أياً منها:

1. **شغّل `clasp status`** في مجلد المشروع — اعرض قائمة الملفات التي سيتم دفعها
2. **اعرض القائمة للمستخدم** وانتظر موافقته الصريحة قبل أي خطوة تالية
3. **ادفع الملفات المعتمدة فقط** بـ `clasp push -f`
4. **تحقق من النشر** بـ `clasp deployments` وأكّد أن الـ deploymentId الصحيح نشط
5. **لا تدفع أبداً** دون عرض الملفات المتغيّرة أولاً — هذا القيد مطلق بلا استثناء

## قواعد إضافية:
- استخدم دائماً `clasp deploy -i <existingId>` — لا تنشئ deployment جديدة
- تحقق من `deployments.json` في جذر المشروع للحصول على الـ ID الصحيح
- بعد النشر، أكّد أن رابط Web App لا يزال يعمل (200/302)
- إذا فشل clasp push، أوقف العملية وأبلّغ المستخدم — لا تحاول مجدداً تلقائياً
