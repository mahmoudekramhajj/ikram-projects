# خوارزمية التسكين الذكي — Smart Room Assignment Algorithm

---

## المدخلات

```
┌─────────────────────────────────────────────────────────┐
│                       المدخلات                           │
├─────────────────────────────────────────────────────────┤
│ 1. رحلة الحاج ← الحجاج (اسم، جواز، جنس، باقة)         │
│ 2. الباقات ← الفنادق لكل باقة (فندق 1/2/3)             │
│ 3. Room Mapping ← الغرف الفعلية (رقم، نوع، حالة)       │
│ 4. Room Type ← نوع الغرفة وعدد الغرف لكل مجموعة        │
│ 5. NUSK Room Type ← بيانات الغرف من منصة نسك            │
│ 6. Guide Rabih ← اسم المرشد + البلد لكل حاج (83%)      │
│ 7. Guide Grouping ← تجميعات المرشدين اليدوية            │
│ 8. عقود السكن ← سعة العقد لكل فندق/باقة                │
│ 9. توفر الغرف ← أنواع الغرف المتاحة لكل باقة           │
└─────────────────────────────────────────────────────────┘
```

## المخرجات

```
┌─────────────────────────────────────────────────────────┐
│                       المخرجات                           │
├─────────────────────────────────────────────────────────┤
│ كل حاج ← رقم غرفة فعلي في كل فندق                      │
│ تقرير التوزيع ← إحصائيات + تنبيهات                      │
│ 26 شيت فندق (ADM-VOCO) ← بيانات التسكين (24 عمود)      │
│ Room Mapping ← محدّث بالحالات                            │
└─────────────────────────────────────────────────────────┘
```

## الربط بين البيانات

```
المفتاح الموحّد = رقم الباقة (PackageId)

الحاج ──(PackageId)──→ الباقة ──(فندق 1/2/3)──→ Room Mapping
                                                       ↓
                                              رقم الغرفة الفعلي

⚠️ لا نقارن أسماء الفنادق — رقم الباقة + ترتيب الفندق هو المرجع
```

## مصادر بيانات الحاج

```
┌──────────────────────────────────────────────────────────────┐
│ البيان              │ المصدر الأساسي    │ المصدر البديل      │
├──────────────────────────────────────────────────────────────┤
│ اسم المرشد          │ Guide Rabih (ع15)  │ Presonal Details   │
│ البلد / الجنسية     │ Guide Rabih (ع16-17)│ رحلة الحاج        │
│ الجنس               │ رحلة الحاج         │ Guide Rabih (ع4)   │
│ رقم المجموعة        │ رحلة الحاج         │ Guide Rabih (ع1)   │
│ نوع الغرفة المطلوب  │ Room Type / NUSK   │ —                  │
│ رقم الباقة          │ رحلة الحاج         │ Guide Rabih (ع18)  │
└──────────────────────────────────────────────────────────────┘
```

## المرحلة 0: التجهيز

```
بداية
  │
  ├──→ اختر الفندق (عبر رقم الباقة + ترتيب الفندق)
  │
  ├──→ اجمع الحجاج غير المسكّنين لهذا الفندق
  │
  ├──→ اجمع الغرف المتاحة من Room Mapping
  │       ├── لو Room Mapping موجود ← استخدمه
  │       └── لو غير موجود ← ولّد الأرقام تلقائياً بنفس الصيغة
  │       رتّبها: رباعية ← ثلاثية ← مزدوجة
  │
  ├──→ اقرأ Guide Rabih ← اسم المرشد + البلد لكل حاج
  │
  ├──→ اقرأ Room Type / NUSK Room Type
  │       لكل مجموعة: عدد الأفراد + نوع الغرفة المطلوب
  │
  ├──→ صنّف كل مجموعة:
  │       │
  │       ├── عدد الأفراد = سعة الغرفة ──→ عائلة
  │       │     ├── عنده مرشد ──→ يدخل التوزيع التلقائي (المرحلة 1)
  │       │     └── بدون مرشد ──→ يدخل التوزيع التلقائي (المرحلة 1)
  │       │
  │       └── عدد الأفراد ≠ سعة الغرفة ──→ مشاركين
  │             ├── عنده مرشد ──→ يُستبعد (المرشد يوزّعه من Guide App)
  │             └── بدون مرشد ──→ يدخل التوزيع التلقائي (المرحلة 2)
  │
  ├──→ رتّب المجموعات:
  │       العائلات أولاً (المرحلة 1)
  │       ثم المشاركين من الأكبر للأصغر (المرحلة 2)
  │
  └──→ انتقل للمرحلة 1
```

### ملاحظة مهمة — كل فندق على حدة:

```
الحاج ممكن عنده حتى 3 فنادق (مكة 1 + مكة 2 + المدينة)
← التوزيع يتم لكل فندق بشكل مستقل
← نفس الحاج ممكن:
   فندق مكة: عائلة (غرفة رباعية كاملة)
   فندق المدينة: مشارك (غرفة رباعية ناقصة)
← التصنيف يُعاد حسابه لكل فندق
```

## المرحلة 1: تسكين العائلات

```
لكل مجموعة مصنّفة "عائلة":
  │
  ├── خذ غرفة متاحة من نفس النوع المطلوب
  │     (رباعية/ثلاثية/مزدوجة)
  │
  ├── أدخل كل الأفراد فيها
  │     (ذكور + إناث معاً — عائلة مسموح)
  │
  ├── الغرفة ← Occupied
  │
  └── التالي

  ⚠️ لو نوع الغرفة المطلوب غير متاح:
      حوّل غرفة أصغر إلى النوع المطلوب
      (مثلاً: ثلاثية ← رباعية)
```

### الحالات:

```
┌──────────────────────────────────────────────────────────────────┐
│ الحالة │ المجموعة          │ الغرفة    │ النتيجة                 │
├────────┼───────────────────┼───────────┼─────────────────────────┤
│   1    │ 4 أشخاص           │ رباعية    │ ✓ ممتلئة                │
│   2    │ 3 أشخاص (2ذ+1أ)   │ ثلاثية    │ ✓ ممتلئة (مختلط—عائلة) │
│   3    │ 2 أشخاص (1ذ+1أ)   │ مزدوجة    │ ✓ ممتلئة (مختلط—عائلة) │
└──────────────────────────────────────────────────────────────────┘

العائلة = عدد الأفراد يساوي سعة الغرفة تماماً
← دائماً غرفة واحدة ← دائماً ممتلئة ← لا استثناءات
← حتى لو عندهم مرشد ← يُسكَّنون تلقائياً (لا قرار يُتخذ)
```

## المرحلة 2: تسكين المشاركين

### الخطوة 2.0: الفصل بالجنس

```
لكل مجموعة مصنّفة "مشاركين" (بدون مرشد فقط):
  │
  ├── افصل الذكور عن الإناث
  │
  ├── الذكور ← قائمة الذكور المشاركين
  │     (مع الاحتفاظ برقم المجموعة + البلد + المرشد)
  │
  └── الإناث ← قائمة الإناث المشاركين
        (مع الاحتفاظ برقم المجموعة + البلد + المرشد)

⚠️ المشاركين التابعين لمرشد ← مُستبعدون
   المرشد يوزّعهم يدوياً من Guide App
```

### الخطوة 2.1: ترتيب القوائم

```
رتّب كل قائمة (ذكور/إناث):
  │
  ├── المجموعات الأكبر أولاً:
  │     مجموعة 3 ذكور ← أولاً (تحتاج 1 فقط لإكمال رباعية)
  │     مجموعة 2 ذكور ← ثانياً (تحتاج 2)
  │     منفرد ← أخيراً (مرن — يكمل أي غرفة)
  │
  └── داخل نفس الحجم: رتّب بالبلد ثم المرشد
      (لتسهيل التطابق بالتفضيلات)
```

### الخطوة 2.2: التوزيع مع التفضيلات

```
لكل مجموعة مشاركين (من الأكبر للأصغر):
  │
  ├── خذ غرفة متاحة من النوع المطلوب
  │
  ├── أدخل أفراد المجموعة
  │
  ├── هل الغرفة ممتلئة؟
  │     │
  │     ├── نعم ← Occupied ← التالي
  │     │
  │     └── لا ← تحتاج إكمال ← ابحث بالتفضيلات
  │
  └── البحث بالتفضيلات لإكمال الغرفة:

      ┌─────────────────────────────────────────────────┐
      │          قائمة التفضيلات (بالترتيب)              │
      │                                                 │
      │  شرط إلزامي: نفس الجنس (دائماً)                │
      │                                                 │
      │  تفضيل 1: نفس المرشد + نفس البلد + منفرد       │
      │  تفضيل 2: نفس المرشد + نفس الجنس               │
      │  تفضيل 3: نفس البلد + نفس الجنس                │
      │  تفضيل 4: أي شخص من نفس الجنس                  │
      │                                                 │
      │  أولوية المنفردين دائماً (أسهل بالنقل)          │
      │                                                 │
      │  ⚠️ التفضيلات تُطبَّق في كل مرة نبحث عن       │
      │  شخص لإكمال غرفة — رباعية أو ثلاثية أو مزدوجة  │
      └─────────────────────────────────────────────────┘
```

### الحالات:

```
┌───────────────────────────────────────────────────────────────────────────────┐
│ الحالة │ المجموعة              │ الغرفة   │ التصرف                            │
├────────┼───────────────────────┼──────────┼───────────────────────────────────┤
│   4    │ 2 (ذ+أ) رباعية       │ مشاركين  │ يُفصلون ← كل واحد مع جنسه        │
│   5    │ 3 (2ذ+1أ) رباعية     │ مشاركين  │ 2ذ مع ذكور + 1أ مع إناث           │
│   6    │ 6 (3ذ+3أ) رباعية     │ مشاركين  │ 3ذ في رباعية + 3أ في رباعية       │
│   7    │ 8 (4ذ+4أ) رباعية     │ مشاركين  │ 4ذ في رباعية + 4أ في رباعية       │
│   8    │ 1 (ذ) رباعية         │ مشاركين  │ قابل للنقل ← يكمل غرفة ناقصة     │
│   9    │ 1 (أ) ثلاثية         │ مشاركين  │ قابلة للنقل ← تكمل غرفة ناقصة    │
│  10    │ 5 (3ذ+2أ) رباعية     │ مشاركين  │ 3ذ+1ذ رباعية + 2أ مع إناث         │
│  18    │ مجموعة بأنواع غرف    │ مشاركين  │ كل شخص حسب طلبه (اللي دفع له)    │
│        │ مختلفة (نادر)        │          │                                   │
└───────────────────────────────────────────────────────────────────────────────┘
```

### الخطوة 2.3: النقل بين أنواع الغرف

```
بعد التوزيع الأولي، لو بقيت غرف ناقصة:
  │
  ├── ابحث عن منفردين يمكن نقلهم لإكمال غرف أصغر
  │     (منفرد في رباعية ← ثلاثية ناقصة أو مزدوجة ناقصة)
  │
  ├── ابحث عن مجموعات صغيرة كاملة يمكن نقلها
  │     (مثلاً: 2 في رباعية ← ثلاثية فيها 1)
  │
  ├── قواعد النقل:
  │     ├── ✓ منفرد ← ينتقل بحرية
  │     ├── ✓ مجموعة 2 كاملة ← تنتقل معاً (لو الغرفة تستوعبهم)
  │     ├── ✗ جزء من مجموعة ← لا يُفصل أبداً
  │     │     (مثال ممنوع: 2 من 3 ينتقلون والثالث يبقى وحده)
  │     └── ✓ التفضيلات تُطبَّق في الغرفة الجديدة
  │
  └── الهدف: أقل غرف ناقصة ممكن

  ⚠️ القاعدة: اغلب المجموعات شخصين (ذكر + أنثى)
     ← بعد الفصل بالجنس = منفردين كثيرين ← سهل النقل والإكمال
```

## المرحلة 3: التحسين

```
بعد تسكين الجميع:
  │
  ├── اجمع كل الغرف الناقصة
  │     (غرف فيها أشخاص لكن مو ممتلئة)
  │
  ├── رتّبها: الأكثر امتلاءً أولاً
  │     (غرفة فيها 3 من 4 قبل غرفة فيها 1 من 4)
  │
  ├── لكل غرفة ناقصة:
  │     │
  │     ├── هل فيه شخص في غرفة ثانية ناقصة يمكن نقله هنا؟
  │     │     │
  │     │     ├── نعم (منفرد أو مجموعة كاملة):
  │     │     │     ├── تحقق من التفضيلات (نفس المرشد + البلد + الجنس)
  │     │     │     ├── انقله
  │     │     │     ├── الغرفة الأولى تمتلئ (أو تقترب)
  │     │     │     └── الغرفة الثانية تفضى ← تعود متاحة
  │     │     │
  │     │     └── لا ← الغرفة تبقى ناقصة (مقبول — الحاج مسكّن)
  │     │
  │     └── التالي
  │
  └── النتيجة: أقل عدد غرف ناقصة + أكثر غرف ممتلئة
```

### مثال التحسين:

```
قبل التحسين:
  غرفة 402 رباعية: 3 ذكور (ناقصة 1)
  غرفة 403 رباعية: 1 ذكر (ناقصة 3)
  غرفة 501 ثلاثية: 1 أنثى (ناقصة 2)

التحسين:
  ← انقل الذكر من 403 إلى 402
  ← غرفة 402: 4 ذكور ✓ ممتلئة
  ← غرفة 403: فاضية ← متاحة
  ← غرفة 501: تبقى 1 أنثى (لا ذكور يدخلون — شرط الجنس)

بعد التحسين:
  غرف ناقصة: 1 (بدل 3)
  غرف تحررت: 1
```

## زر "اكتمل العدد" — خوارزمية التحديث

```
يُضغط بعد انتهاء جميع التعديلات (إضافة/إلغاء/تبديل)
لا يعمل تلقائياً — الموظف يعدّل براحته ثم يضغط الزر

بداية
  │
  ├──→ اقرأ التسكين الحالي (من شيتات الفنادق الـ 26)
  │
  ├──→ اقرأ بيانات الحجاج الحالية (من رحلة الحاج)
  │
  ├──→ قارن:
  │     │
  │     ├── حجاج جدد (في رحلة الحاج + بدون غرفة)
  │     │     ← أدخلهم بنفس الخوارزمية (تفضيلات + جنس)
  │     │     ← الأولوية: أكمل غرفة ناقصة قبل فتح جديدة
  │     │
  │     ├── حجاج ملغيين (عندهم غرفة + مو في رحلة الحاج)
  │     │     ← أخرجهم من غرفهم
  │     │     ← الغرفة صارت ناقصة ← تدخل مرحلة التحسين
  │     │
  │     ├── حجاج تغيّر فندقهم (الفندق في رحلة الحاج ≠ الفندق في الغرفة)
  │     │     ← أخرجهم من الفندق القديم
  │     │     ← أدخلهم في الفندق الجديد بنفس الخوارزمية
  │     │
  │     └── لا تغيير ← لا شيء
  │
  ├──→ شغّل مرحلة التحسين (المرحلة 3)
  │     ← املأ الغرف الناقصة قدر الإمكان
  │
  ├──→ اعرض تقرير التحديث:
  │
  │     ┌──────────────────────────────────────────┐
  │     │            تقرير التحديث                  │
  │     ├──────────────────────────────────────────┤
  │     │ جدد: 3 حجاج                              │
  │     │   أحمد ← KANJQ045 (أُكمل مكان فاضي)     │
  │     │   سارة ← KANJTX12 (غرفة جديدة)          │
  │     │ ملغيين: 1 حاج                            │
```

## القواعد الذهبية (ملخص)

```
┌─────────────────────────────────────────────────────────────────────┐
│                         القواعد الذهبية                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. كل حاج لازم يُسكَّن (دفع — حقه محفوظ)                         │
│                                                                     │
│  2. العائلة = عدد الأفراد يساوي سعة الغرفة تماماً                  │
│     ← مختلط مسموح (ذكور + إناث)                                    │
│     ← يُسكَّنون تلقائياً حتى لو تابعين لمرشد                      │
│                                                                     │
│  3. أي حالة ثانية = مشاركين                                        │
│     ← يُفصلون بالجنس (ذكور مع ذكور، إناث مع إناث)                 │
│                                                                     │
│  4. مشاركين تابعين لمرشد = المرشد يوزّعهم يدوياً                   │
│     مشاركين بدون مرشد = التوزيع التلقائي                           │
│                                                                     │
│  5. لا تفتح غرفة جديدة وفيه غرفة ناقصة من نفس الجنس               │
│                                                                     │
│  6. رقم الباقة = المرجع الوحيد (لا نقارن أسماء فنادق)              │
│                                                                     │
│  7. لا تفصل مجموعة (انقل كاملة أو لا تنقل)                        │
│                                                                     │
│  8. المنفردين أولوية بالنقل والإكمال                                │
│                                                                     │
│  9. التفضيلات (تُطبَّق دائماً):                                    │
│     شرط إلزامي: نفس الجنس                                          │
│     تفضيل 1: نفس المرشد + نفس البلد                                │
│     تفضيل 2: نفس المرشد                                            │
│     تفضيل 3: نفس البلد                                             │
│     تفضيل 4: أي شخص مناسب                                          │
│                                                                     │
│ 10. كل فندق = توزيع مستقل بالكامل                                  │
│     (نفس الحاج ممكن عائلة بفندق ومشارك بفندق ثاني)                │
│                                                                     │
│ 11. "توزيع ذكي" = من الصفر                                         │
│     "اكتمل العدد" = تحديث التغييرات دفعة واحدة                     │
│                                                                     │
│ 12. كل شخص يحصل على نوع الغرفة الذي دفع ثمنه                      │
│     (لو المجموعة فيها أنواع مختلفة ← كل واحد حسب حجزه)            │
│                                                                     │
│ 13. لو فندق بدون Room Mapping ← ولّد الأرقام تلقائياً              │
│     بالصيغة: [المدينة][رمز الفندق][نوع الغرفة][رقم تسلسلي]        │
│                                                                     │
│ 14. لو نوع الغرفة المطلوب غير متاح ← حوّل غرفة أصغر               │
│     (ثلاثية ← رباعية) — الغرف دائماً كافية حسب العقد              │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
